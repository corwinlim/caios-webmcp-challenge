# Contributing

Thank you for improving this synthetic WebMCP demonstration.

By submitting a contribution, you agree that it is licensed under
Apache-2.0 and confirm that you have the right to provide it.

Do not submit:

- production CAIOS source code or private implementation details;
- real customer or pet records;
- API keys, tokens, passwords, cookies, or `.env` files;
- proprietary prompts, models, database schemas, nutrition logic, or clinical logic;
- third-party material that you are not authorized to license.

Keep the project synthetic, browser-only, narrowly scoped, and reproducible.
Run `npm test && npm run typecheck && npm run build` before opening a pull request.
